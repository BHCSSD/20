## Step 2: Defining the Map Layout

Instead of hardcoding raw pixel values, we use a grid layout object containing nested arrays of `[column, row]` coordinate pairs to place items on top of our grid.

```javascript
let layout = {
  trees: [ [2, 2], [2, 3], [5, 8], [6, 8] ],
  mountains: [ [0, 0], [1, 0], [0, 1] ],
  roads: [ [4, 0], [4, 1], [4, 2], [4, 3], [5, 3], [6, 3] ]
}

```
