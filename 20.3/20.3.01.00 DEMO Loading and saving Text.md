> [!NOTE]
> ### INFODUMP
> 
> 
> In p5.js, you can mix **HTML elements** (textboxes, buttons, file inputs) directly with your canvas.
> These are created using p5 DOM helper functions:
> * `createInput()` makes a text entry box
> * `createButton()` makes a standard clickable button
> * `createFileInput()` makes a button for uploading local files
> 
> 
> Files can be **saved** with `saveStrings()` and **loaded** using event callbacks.
> All file operations are **asynchronous**-they run in the background without freezing your canvas animation loop.

### 1. Create a Textbox

1. **Make a Textbox**
* Create an input field with `createInput("Type something here...")`.
* Store it in a variable (eg:`inputBox`).
* Use `inputBox.position(x, y)` to place it relative to the top-left of the page.
* Use `inputBox.size(width)` to set its width in pixels.


2. **Display the User’s Input**
* Read the typed string using `inputBox.value()`.
* Display it on the canvas with `text("You typed: " + inputBox.value(), x, y)`.



```javascript
let inputBox;

function setup() {
  createCanvas(400, 200);

  // 1. Create a textbox (HTML input field)
  inputBox = createInput("Type something here...");
  inputBox.position(20, 30);  // Position (x, y)
  inputBox.size(200);         // Width in pixels

  textSize(16);
}

function draw() {
  background(240);
  
  // 2. Safely read and render text from the input element
  if (inputBox) {
    text("You typed: " + inputBox.value(), 20, 100);
  }
}

```

> [!NOTE]
> * `.value()` retrieves whatever string is currently inside the input field.
> * HTML elements sit on top of the web page overlaying the canvas—they are not rendered directly within the p5 drawing context.
>

### 2. Add a Button to Save as `.txt`

1. **Add a Button for Saving the File**
* Use `createButton("Save as .txt")` to create an HTML button.
* Position it with `saveButton.position(x, y)`.
* Attach an event listener using `saveButton.mousePressed(saveText)`. This tells the browser to run `saveText()` when clicked.
* **Note:** Pass the function name `saveText` as a reference  **DO NOT** include parentheses `()`.


2. **Define the `saveText()` Function**
* Extract the current string with `inputBox.value()`.
* Save the file using `saveStrings([textToSave], "myNotes.txt")`.
* Log `"File saved!"` to the console to confirm execution.



```javascript
let inputBox;
let saveButton;

function setup() {
  createCanvas(400, 200);

  inputBox = createInput("Type your notes...");
  inputBox.position(20, 30);
  inputBox.size(250);

  // 1. Make a button that triggers a file save
  saveButton = createButton("Save as .txt");
  saveButton.position(20, 70);
  saveButton.mousePressed(saveText); // Triggers saveText on click
}

function saveText() {
  // 2. Get the current text and download it
  let textToSave = inputBox.value();
  saveStrings([textToSave], "myNotes.txt");
  print("File saved!");
}

```

> [!NOTE]
> * `saveStrings()` expects an array of strings as its first argument (where each array element represents a line of text). Wrapping your string in square brackets `[textToSave]` converts it into a single-item array.
>

### 3. Upload and Display a `.txt` File

1. **Add a File Upload Button**
* Use `createFileInput(handleFile)` to generate an HTML file picker 
* `handleFile` is a callback function that runs automatically whenever the user selects a file.
* Position the element with `fileInput.position(x, y)`.


2. **Define `handleFile(file)**`
* Verify the file type before reading data:
```javascript
if (file.type === 'text')

```


* Access the full text content via `file.data` and store it in a variable (`loadedText`).


3. **Display the Uploaded File**
* Draw the raw string stored in `loadedText` directly on the canvas using `text()`.



```javascript
let fileInput;
let loadedText = "";

function setup() {
  createCanvas(500, 300);
  textSize(16);

  // 1. Create a file upload button element
  fileInput = createFileInput(handleFile);
  fileInput.position(20, 20);
}

function handleFile(file) {
  // 2. Verify file type and extract file contents directly
  if (file.type === 'text') {
    loadedText = file.data;
  } else {
    print("Not a text file!");
  }
}

function draw() {
  background(240);
  text("Upload a .txt file to display its contents:", 20, 70);

  // 3. Display the raw uploaded string on the canvas
  text(loadedText, 20, 110, 460, 180); 
}

```

> [!NOTE]
> * `file.data` contains the raw content of the uploaded text file as a single string.
> * Using the 4-argument `text(loadedText, x, y, width, height)` syntax automatically wraps the text within a bounding box without requiring any manually split arrays.
> 
>

### 3. Upload and Display a `.txt` File

6. **Add a File Upload Button**

   * Use `createFileInput(handleFile)` to make a file picker button.
      * The `handleFile` is a function we create to .... handle the file
      * When the user uploads a file, the `handleFile()` function will run automatically. 
   * Position it with `fileInput.position(20, 20)`.
 

7. **Defining handleFile(file)**

   * Inside `handleFile(file)`, we need to check if the uploaded file is a text file using:

     ```js
     if (file.type === 'text')
     ```
   * This helps prevent crashes if someone uploads the wrong type of file

   ~* Use `file.data.split('\n')` to break the text file into *separate lines*.~
      ~* Each time the code sees a new line that line of text becomes one item in a list (array).~
      ~* `\n` is a new line indicator.~
      ~* The `\` is located above your enter key~


     ```js
     //["Line one", "Line two", "Line three"]
     ```
   * This makes it easier to draw or edit each line separately on the canvas.
     * no it wasn't, it was dumb and added needless complexity for this level of the course.  

5. **Display Each Line of the Uploaded File**

   * In the `draw()` function, loop through the list with a `for` loop:

     ```js
     for (let i = 0; i < fileContent.length; i++) {
       text(fileContent[i], 20, 100+(i*20) );
     }
     ```
   


```javascript
let fileInput;// LOOK AT ME
let fileContent = [];// ME TOO

function setup() {
  createCanvas(500, 300);
  background(240);
  textSize(16);

  //6. updlaod buttons
  fileInput = createFileInput(handleFile);
  fileInput.position(20, 20);
 }

function handleFile(file) {
  // 7. Make sure it's a text file
  if (file.type === 'text') {
    fileContent = file.data.split('\n'); //8. split into lines
  } else {
    print("Not a text file!");
  }
}

function draw() {
  background(240);
  text("Upload a .txt file to display its contents:", 20, 60);

  // 9. Show each line of the uploaded file
  for (let i = 0; i < fileContent.length; i++) {
    text(fileContent[i], 20, 100 + i * 20);
  }
}
```

> [!NOTE]
> **IMPORTANT NOTE:**
>
> * The `handleFile()` function automatically runs after a file is selected.
> * `file.data` gives you the text inside the file.
> * `.split('\n')` makes a new entry into your list with the line info
