## Q2: Iterating Over JSON Objects

Trace the loop and determine what is printed to the console.

```json
{
  "storePrices": {
    "apples": 1.5,
    "bananas": 0.75,
    "cherries": 3.0,
    "dates": 2.5
  }
}

```

```javascript
function setup() {
  let budget = 5.0;
  let affordable = [];

  for (let item in storePrices) {
    let price = storePrices[item]

    if (price <= budget) {
      affordable.push( item.toUpperCase() )
      budget -= price;
    }//end if

  }//end for

  console.log(`Bought: ${affordable.join(", ")} | Remaining Budget: $${budget}`)
}

```

> [!INFO]
> 
> `Object.keys()` and `Object.values()` are used to extract data from an object into an array.
> * **`Object.keys(obj)`** extracts all the **property names** (keys) from an object and returns them as an array of strings.
> * **`Object.values(obj)`** extracts all the **property values** from an object and returns them as an array.
> 
> 
> ```javascript
> let user = {
>   name: "Alex",
>   age: 25,
>   role: "Developer"
> };
> 
> let keys = Object.keys(user) // Output: ["name", "age", "role"]
> 
> let values = Object.values(user) // Output: ["Alex", 25, "Developer"]
> ```
> 
> 
> ### Why Use Them?
> 
> 
> They let you to use standard array methods like `.length`, `.forEach()`, or `for` loops on object data, which is especially useful when iterating through JSON objects.

## Q4: Extracting Keys and Values with Object Methods

Trace the code using `Object.keys()` and `Object.values()`.

```json
{
  "classScores": {
    "Assignment 1": 90,
    "Assignment 2": 80,
    "Midterm": 85,
    "Final Project": 95
  }
}

```

```javascript
function setup() {
  let keys = Object.keys(classScores)
  let values = Object.values(classScores)
  
  let totalScore = 0
  let highScoringTasks = 0

  for (let i = 0; i < values.length; i++) {
    totalScore += values[i]

    if (values[i] >= 90) {
      highScoringTasks++
    }

  }//end for

  let average = totalScore / keys.length
  console.log(`Avg: ${average} | High Scores: ${highScoringTasks}`)
}

```
