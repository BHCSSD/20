### **Level 1: Core Functionality (Up to 60%)**

*Build the foundation: display data and set up basic navigation.*

* **Core Requirement (Required for all):**
  * Display the Pokémon’s `hires` image alongside its Bio-Data (Species description, Height, Weight)
  * Include a dedicated text block for the main description

* **Navigation Options: PICK 1:**
  * **Option 1A: Sequential:** Add "Next" and "Previous" buttons to cycle through Pokémon IDs in numerical order.
  * **Option 1B: Chaos Jump:** Add a "Random" button to jump directly to any Pokémon in the database.
  


---

### **Level 2: Interactivity & Feedback (Up to 70%)**

*Expand control features and enhance visual presentation.*

* **Core Requirement:** Display special `ability` data clearly on the screen (if present).
* **Feature Options PICK 2:**
  * **Option 2A: Dual Navigation:** Implement **both** Sequential ("Next"/"Previous") and "Random" navigation controls.
  * **Option 2B: Dynamic Accent Colors:** Automatically change the background or UI accent color based on the Pokémon’s primary type
    * Green for Grass, Blue for Water etc
  * **Option 2C: Language Toggle:** Add a button to toggle the Pokémon’s displayed name between English, Japanese, Chinese, and French

---

### **Level 3: Dynamic Type Filtering (Up to 80%)**

*Filter Pokémon dynamically using data loops and UI dropdowns.*

* **Filtering Options Pick 1:**
  * **Option 3A: Hardcoded Filtered Random:** Create a static dropdown menu `createSelect` with predefined types (Fire, Water, Grass etc). When "Random" is clicked with a filter selected, pick a random Pokémon *only* from that specific type.
  * **Option 3B: Dynamic Dropdown Generator (The Grocery Store Method):** Automatically populate your type dropdown on startup by scanning the database with a `for` loop, using an array, `.includes()`, and `!` to extract unique types without hardcoding.
  * **Option 3C: Text Box Search:** Create a text input field `createInput` that filters and displays Pokémon by matching typed text against Pokémon names or IDs.Automatically update the displayed Pokémon as the user types, or trigger the search via a dedicated "Search" button.



> [!TIP]
> **The Grocery Store Method:**
> 1. Pick up a Pokémon.
> 2. Look at its type (e.g. "Fire").
> 3. Check your list: "Is 'Fire' already on my list?"
> 4. If **No**, add it. If **Yes**, ignore it.
> 
> 
> *Only run this extraction once right after the JSON loads to protect performance.*

---

### **Level 4: Global Type Analytics (Up to 90%)**

*Perform database analysis and stat comparisons.*

* **Analytics Needs to parts:**
  * **Part 4A:  Text-Based Stat Comparison:** Create a function that calculates the average HP, Attack, and Defense for all Pokémon matching the current Pokémon's primary type. Display the current Pokémon's stats side-by-side with the Global Type Average and label each as **"Above Average"** or **"Below Average"**.
  * **Part 4B: Visual Stat Indicators & Performance Optimization:** Display the comparison using visual progress bars or meters comparing stats to type averages.

**Efficiency Rule:** Calculations must only execute when the selected Pokémon changes, do **NOT** run calculations inside the `draw()` loop.

let pokeDex;
let pokeImg;
let currentIndex = 0; //which poke to pick


async function loadStuff() {
  pokeDex = await loadJSON("pokedex.json")
  // Load the initial image
  await updatePokemon()
}


//helper to update the image when index changes
async function updatePokemon() {
  if (pokeDex) {
    let url = pokeDex[currentIndex].image.hires
    pokeImg = await loadImage(url)
  }
}

async function setup() {
  createCanvas(400, 400);
  await loadStuff()
  imageMode(CENTER)
}

function draw() {
  background(220);
  
  if (pokeDex && pokeImg) {
    textSize(32)
    textAlign(CENTER)
    fill(0)
    text(pokeDex[currentIndex].name.english,200,40)
    
    image(pokeImg, 200, 200, 250, 250)
 
    textSize(16)
    text("Click mouse to see the next pokemon", 200, 380)
  }
}


async function mousePressed() {
  currentIndex = (currentIndex + 1) % pokeDex.length
  

  pokeImg = null
  await updatePokemon()
}
