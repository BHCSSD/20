1. **Flag variable (`isValid = False`)**
   A boolean flag tracks whether valid input has been received.
   - Starting it at `False` makes sure the loop runs at least once.

3. **The Validation Loop (`while not isValid:`)**
   The loop continues repeating as long as `isValid` stays `False`.

4. **Prompting for Input (`input(...)`)**
   `input()` stores whatever the user types as a string `str`, even if they type digits

5. **Type Conversion & Error Handling `try / except`**
   - **`try:`** Attempts to convert `userInput` into a floating-point number using `float(userInput)`. If it succeeds, `isValid` is set to `True`, which terminates the loop on the next check.
   - **`except:`** If the user enters non-numeric text (like `"hello"`), `float()` raises a `ValueError`. Instead of crashing, Python jumps to the `except` block, prints the error message, leaves `isValid` as `False`, and repeats the loop.
