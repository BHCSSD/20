> [!NOTE]
> ## INFODUMP:
> 
> 
> In programming, a **flag variable** is a variable that keeps track of a **condition**, usually whether something **has happened** or not.
> * It’s called a “flag” because it **raises a signal** in your code when a certain event occurs.
> 
> 
> Think of it like a switch: `true` means “yes, this happened,” and `false` means “no, it hasn’t happened yet.”
> ### **Flags as Latches (Counting Hits)**
> 
> 
> Flags are also critical when counting events like collisions or button clicks.
> Because the `draw()` loop runs **60 times per second**, a simple condition like `if (touching) { score++; }` will add 60 points per second while remaining in contact.
> To add **only 1 point per entry**, we use a flag as a **latch**:
> 1. **Initial Contact:** If `touching` is `true` **AND** the flag is `false`, increment the score and flip the flag to `true` (closing the latch).
> 2. **Sustained Contact:** While staying inside, the flag remains `true`, blocking further score additions.
> 3. **Exit:** When leaving the shape, set the flag back to `false` (opening the latch for the next hit).
> 
>

### **Part 1: Visual State (colour Toggle)**

We want to **change the colour of a circle** when the mouse moves over it using a flag variable.

```javascript
let isHit = false //this flag tracks if the mouse is over the circle
let selectedColour = "green"

function setup() {
  createCanvas(400, 400);
}

function draw() {
  background(220);

  //check collision
  isHit = hitBox(mouseX, mouseY, 300, 100)

  //update colour based on flag state
  if (isHit) {
    selectedColour = "orange"
  } else {
    selectedColour = "green"
  }

  fill(selectedColour)
  circle(300, 100, 100)
}

function hitBox(x1, y1, x2, y2) {
  if (dist(x1, y1, x2, y2) < 50) {
    return true
  } else {
    return false
  }
}//end of hitBox

```

### **Part2: Single-Point Counter (Latch Pattern)**

To keep track of a **hit count** without accidentally scoring 60 points a second while hovering over the circle.

```javascript
let isHit = false //flag acting as a latch
let hitCount = 0;
let selectedColour = "green"

function setup() {
  createCanvas(400, 400);
  textSize(20)
}

function draw() {
  background(220);

  //checks physical contact THIS frame
  let touching = hitBox(mouseX, mouseY, 300, 100)

  //1. mouse is touching AND latch is open (isHit is false)
  if (touching == true && isHit == false) {  
    hitCount+=1      //score only goes up ONCE
    isHit = true    //close the latch to avoid infinite money glitch
  }

  //2. reset Latch when mouse is not touching
  if (touching==false) {
    isHit = false   //open the latch for next time
  }

  // Visual
  if (touching) {
    selectedColour = "orange"
  } else {
    selectedColour = "green"
  }

  fill(selectedColour)
  circle(300, 100, 100)

  fill(0)
  text(`Total Hits: ${hitCount}`, 20, 40)
}


function hitBox(x1, y1, x2, y2) {
  return dist(x1, y1, x2, y2) < 50  // this is a short cut... any time you use >,< etc it returns true or false
}

```

---

### **the break down**

1. make a **flag variable**: `isHit = false`.
2. check if the mouse is touching the circle using a local variable (`touching`).
3. **State Change:** When the mouse first enters, `touching == true` and `isHit == false`. This condition triggers the hit counter **once** and flips the flag to `isHit = true`
4. **Sustained Touch:** On following frames, `isHit` is `true`, so the counter will not increase again while lingering inside.
5. **Reset:** When the mouse leaves, `touching == false`, resetting `isHit = false` so the circle can be scored again on the next pass.

| Mouse Position | Physical Contact (`touching`) | Flag State (`isHit`) | Counter Action |
| --- | --- | --- | --- |
| **Outside** | `false` | `false` | None |
| **First frame entering** | `true` | `false` --> `true` | **`hitCount+=1`** |
| **Hovering inside** | `true` | `true` | None (Latch blocked) |
| **Exiting circle** | `false` | `true` --> `false` | Latch opens |
