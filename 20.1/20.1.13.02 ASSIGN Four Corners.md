## **Part 1: Core Assignment**

### **1. Player Movement & Wrapping**

Create a `movement()` function that updates the `sprite` object using **WASD** tank controls.

* **Rotation (A / D):** Modify `sprite.angle` to rotate the sprite left or right.
* **Movement (W / S):** Move the sprite forward or backward along its current angle.
* **Execution:** Call `movement()` inside `draw()` so it updates every frame.
* **Screen Wrapping:** If the sprite leaves one edge of the canvas, make it reappear on the opposite edge.

### **3. Shape Collision Detection**

* Complete the `hitBox()` function using p5's built-in `dist()` function to calculate distance between points.
* Call `hitBox()` inside `draw()` to test if the sprite collides with each shape.
* **When a collision occurs:**
  * Change the colour of **only** the shape that was hit.
  * Set that shape's `isHit` flag to `true`.



> [!TIP]
> Test collision detection on **one shape first**. Once it works reliably, expand the logic to the other shapes.

// Draw regular polygon
function polygon(x, y, radius, npoints) {
  const angle = 360 / npoints; 
  beginShape();
  for (let i = 0; i < npoints; i++) {
    const currentAngle = angle * i - 90;
    const sx = x + cos(currentAngle) * radius;
    const sy = y + sin(currentAngle) * radius;
    vertex(sx, sy);
  }
  endShape(CLOSE);
}

// Draw star
function drawStar(startX, startY, sides, radius1, radius2) {
  beginShape();
  for (let i = 0; i < sides * 2; i++) {
    let angle = map(i, 0, sides * 2, 0, 360) + 15;
    let r = (i % 2 === 0) ? radius1 : radius2;
    let x = cos(angle) * r + startX;
    let y = sin(angle) * r + startY;
    vertex(x, y);
  }
  endShape(CLOSE);
}
