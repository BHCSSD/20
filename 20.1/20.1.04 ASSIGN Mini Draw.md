## **Big Ol' Info Dump**

> [!NOTE]
> **What are Parameters?**
> * Parameters are **placeholders** in a function definition. They are variables that the function uses to perform actions.
> 
> 
> ```javascript
> function drawThingy(cx, cy, size, colour) {
>   fill(colour)
>   ellipse(cx, cy, size) // cx and cy parameters control position
> }
> 
> ```
> 
> 
> Here, `cx`, `cy`, `size`, and `colour` are **parameters**. They don’t have actual values until the function is **called**.
> * **Key Point:** Parameters define the **inputs** your function needs to work.
> 
> 

---

> [!NOTE]
> **What are Arguments?**
> * Arguments are the **actual values** you pass into a function when you call it.
> 
> 
> ```javascript
> drawThingy(100, 200, 50, 'red') // Calling the function with arguments
> 
> ```
> 
> 
> * `100` --> `cx`
> * `200` --> `cy`
> * `50` --> `size`
> * `'red'` --> `colour`
> * **Key Point:** Arguments are plugged **into the parameters** when the function runs.
> 
> 

---

> [!NOTE]
> **Naming Parameters**
> * When writing custom drawing functions, it’s best to **use consistent parameter names**.
> * Always keep parameters in a predictable order (like `cx, cy, size, col`), just like p5.js does.
> 
> 
> This makes reading your code faster and debugging much easier.
> | Standard Parameter | Meaning |
> | --- | --- |
> | `cx` | Center X coordinate |
> | `cy` | Center Y coordinate |
> | `size` | General size (diameter, width, height, or scale) |
> | `col` | Fill color of the object |
> | `strokeCol` | Outline color |
> | `angle` | Rotation angle, if applicable |
> 
> 

---

> [!TIP]
> * Remember to use `push()` and `pop()` inside your drawing functions to isolate style formatting (`fill`, `stroke`, `strokeWeight`).
> * `stroke()` controls outline color.
> * `strokeWeight()` controls line thickness.
> * Use `noFill()` when you only want outlines.
> 
>

## Quadrants & Requirements

### Quadrant 1: Target Tracking

* **Function:** `drawCrossHair(cx, cy, targetSize, isLockedOn)`
* **Requirements:**
   * Draw a target reticle using concentric circles and crosshair lines.
   * When the mouse is inside Quadrant 1, update target coordinates (`targetX`, `targetY`) so the reticle tracks toward `mouseX` and `mouseY`.
   * Clicking inside Quadrant 1 toggles `isLockedOn` between `true` and `false`.
   * If `isLockedOn` is `true`, change the crosshair color (e.g., from green to red) or make the outer ring rotate.



---

### Quadrant 2: Health / Energy Meter

* **Function:** `drawHealthBar(cx, cy, currentHp, maxHp, barColor)`
* **Requirements:**
   * Draw a frame/container for the health bar and a decorative heart or potion icon next to it using basic shapes.
   * Use parameter math inside the function (`let fillWidth = (currentHp / maxHp) * barWidth;`) to draw the inner health bar proportionately.
   * **Interactivity:** Clicking inside Quadrant 2 decreases `playerHp`. If HP drops below `0`, reset it back to `maxHp`.
   * **Dynamic Styling:** Change `barColor` based on remaining HP (e.g., green when high, flashing red when low).



---

### Quadrant 3: Water Ripple Splash

* **Function:** `drawSplash(cx, cy, rippleSize)`
* **Requirements:**
   * Draw a solid blue background rectangle filling Quadrant 3.
   * Draw at least **4 concentric ellipses** centered at `(cx, cy)`.
   * Use semi-transparent colors via `fill(r, g, b, alpha)` or `stroke(r, g, b, alpha)`
      * (alpha range: `0` invisible to `255` solid).
   * **Interactivity:** Clicking inside Quadrant 3 sets `splashX` and `splashY` to `mouseX` and `mouseY` and resets `rippleSize = 0`.
   * In `draw()`, expand `rippleSize` over time so the rings animate outward.



---

### Quadrant 4: Arcade Coin Block

* **Function:** `drawCoinBlock(cx, cy, size, coinCount)`
* **Requirements:**
   * Draw a classic arcade item block (e.g., a glowing box with a question mark or star).
   * Display the current coin count above the block using `text()` (e.g., `"COINS x 12"`).
   * **Hover Effect:** When the mouse is inside Quadrant 4, increase `size` slightly.
   * *Slightly Advanced Option:* Have the block grow and shrink automatically (pulse) when hovered over
   * **Click Effect:** Clicking inside the coin block increments `coinCount` by 1 and temporarily offsets `cy` upward to make the block pop.
