## **Big Ol' Info Dump:**


> [!NOTE]
>**What are Parameters?**
>
>* Parameters are **placeholders** in a function definition. They are variables that the function can use to perform actions.
>
> ```javascript
> function drawThingy(cx, cy, size, colour) {
>  fill(colour);
>  ellipse(cx, cy, size); // cx and cy parameters control position
> }
> ```
> Here, `cx`, `cy`, `size`, and `colour` are **parameters**.
> They don’t have actual values until the function is **called**.
>
>   * **Key point:** Parameters define the **inputs** your function needs to work.
>
> ---


> [!NOTE]
> **What are Arguments?**
>
> * Arguments are the **actual values** you give to a function when you call it.
>
> ```javascript
> drawBalloon(100, 200, 50, 'red')//this is calling the function
> ```
>
> * `100`-`cx`
> * `200`-`cy`
> * `50`-`size`
> * `'red'`-`colour`
>   * **Key point:** Arguments are plugged **into the parameters** when the function runs.
> ---


> [!NOTE]
>  **Naming Parameters**
> * When writing functions that, it’s best to **use consistent parameter names**
> * always use the same order cx,cy,size,col just like p5js does.
>
> This makes reading your code faster and debugging easier.
>
> | Standard Parameter | Meaning                                          |
> | ------------------ | ------------------------------------------------ |
> | `cx`               | Center x-coordinate of the drawing              |
> | `cy`               | Center y-coordinate of the drawing              |
> | `size`             | General size (diameter, width, height, or scale) |
> | `col`              | Fill colour of the object                         |
> | `strokeCol`        | Stroke (outline) colour                           |
> | `angle`            | Rotation angle, if applicable                    |
> ---

### Quadrant 1: Interactive Balloon

Write a function named `drawBalloon(size, col)` to draw a custom balloon

**What to include:**

* **Balloon Body:** Use an `ellipse()` filled with your parameter color (`col`).
* **Details:** Add a small triangle/ellipse at the bottom for the knot, and use `line()` to draw a hanging string.
* **Highlight:** Draw **4 thin lines** across one side of the balloon body to create a "reflection cross-hatch" highlight.
* **Interactivity:** Make the balloon change size when you interact with it (e.g. growing when a key is held or when `mouseDragged()` is triggered).
  *  
* **On-Screen Instruction:** Use the `text()` function to write instructions inside Quadrant 1 explaining how to interact with it (e.g. `"Drag mouse in Q1 to inflate"`).
* **Boundary Guard:** If your interaction uses the mouse position, use `if` statements to make sure it **only** triggers when the cursor is inside Quadrant 1

> [!TIP]
> `scale()`
> 
> The `scale()` function shrinks or expands everything drawn **after** it.
> By default, `1.0` is 100% size (normal), `0.5` is 50% size, and `2.0` is 200% size.
> 
> By default, `scale()` scales everything relative to the origin **(0, 0)**
> *  This means scaling an object also pushes it further away across the screen.
> 
> ```javascript
> // BAD: The shape grows, but it ALSO moves down and to the right
> scale(2.0);
> ellipse(100, 100, 50, 50); 
> 
> ```
> 
>  **USE `push()`, `translate()`, and `pop()`**
>  To scale a shape **in place** without moving it, follow these 4 steps in order:
>  
>  1. **Save state with push():** Isolates transformation settings.
>     Call `push()` so your `scale()` doesn't mess up the rest of your sketch.
>  2. **Move origin to shape center with translate(x, y):**
>  Use `translate(x,y)` to temporarily move $(0,0)$ to where you want your shape to sit.
>  
>  3. **Apply scale(factor):**    Scale relative to the new origin.
>  4. **Draw shape at (0, 0) and restore with pop():**
>  Draw your shape at coordinate (0,0) , then call `pop()` to reset the coordinate system back to normal.
>

### Quadrant 2: Three-Stripe Flag

Write a function named `drawThreeStripeFlag(cx,cy ,country, col1, col2, col3)`

**What to include:**

* **Country Label:** Use `text()` to print the country name at the top of the quadrant.
* **Three Vertical Stripes:** Use `rect()` to draw three side-by-side vertical stripes.
* **Proportions:** Divide the total width of your flag area by 3 so all stripes are perfectly equal in size.
* **Clean Edges:** Call `noStroke()` before drawing the flag rectangles so there are no black border outlines between the colors.

Goal: do not hard code the `x,y `for any of the shapes or the text. Every thing you draw needs to be refferencing the parameters.

### Quadrant 3: Water Ripple Splash

Write a function named `drawSplash(cx, cy)` that simulates a ripple expanding outward like a pebble hitting a calm pond.

**What to include:**

* **Water Background:** Draw a solid blue rectangle filling all of Quadrant 3.
* **Interactive Trigger:** The splash should only appear or trigger when you click **inside** Quadrant 3
  * Use `mousePressed()`
* **Layered Circles:** Draw at least **4 concentric ellipses** at cx, cy
* **Transparency:** Pass 4 arguments to `fill()` (Red, Green, Blue, Alpha) to make the circles semi-transparent 
  * **Dynamic Sizing:** Use the `random()` function to give the rings slight variations in size or thickness so the ripple feels organic and animated.

> **Code Tip:** Alpha values range from 0 (completely invisible) to 255 (fully solid). Stacking semi-transparent shapes creates depth.

* **Rain Effect:** in a function called `drawRain()` Use a draw multiple diagonal `line()` shapes across Quadrant 4 to represent falling rain drops.
