## **Big Ol' Info Dump**

> [!NOTE]
> **What are Parameters?**
>
> * Parameters are **placeholders** in a function definition. They are variables that the function uses to perform actions.
>
> ```javascript
> function drawThingy(cx, cy, size, colour) {
>   fill(colour)
>   ellipse(cx, cy, size) // cx and cy parameters control position
> }
> ```
>
> Here, `cx`, `cy`, `size`, and `colour` are **parameters**. They don't have actual values until the function is **called**.
>
> * **Key Point:** Parameters define the **inputs** your function needs to work.

---

> [!NOTE]
> **What are Arguments?**
>
> * Arguments are the **actual values** you pass into a function when you call it.
>
> ```javascript
> drawThingy(100, 200, 50, 'red') // Calling the function with arguments
> ```
>
> * `100` --> `cx`
>
> * `200` --> `cy`
>
> * `50` --> `size`
>
> * `'red'` --> `colour`
>
> * **Key Point:** Arguments are plugged **into the parameters** when the function runs.

---

> [!NOTE]
> **Naming Parameters**
>
> * When writing custom drawing functions, it's best to **use consistent parameter names**.
> * Keep parameters in a predictable order, such as `cx, cy, size, col`, just like p5.js does.
>
> This makes your code easier to read and debugging much easier.
>
> | Standard Parameter | Meaning                                          |
> | ------------------ | ------------------------------------------------ |
> | `cx`               | Center X coordinate                              |
> | `cy`               | Center Y coordinate                              |
> | `size`             | General size (diameter, width, height, or scale) |
> | `col`              | Fill color of the object                         |
> | `strokeCol`        | Outline color                                    |
> | `angle`            | Rotation angle, if applicable                    |

---

> [!TIP]
>
> * Remember to use `push()` and `pop()` inside your drawing functions to isolate style formatting (`fill`, `stroke`, `strokeWeight`).
> * `stroke()` controls the outline color.
> * `strokeWeight()` controls line thickness.
> * Use `noFill()` when you only want outlines.
